# 🇸🇱 Sierra Leone IELTS Prep

Sierra Leone IELTS Prep is a modern exam preparation platform designed to help students in Sierra Leone and beyond achieve high IELTS band scores for study, work, and migration opportunities.

---

## 🚀 Features
- Full IELTS mock exam system  
- Listening practice with audio support  
- Reading comprehension passages  
- Writing Task 1 and Task 2 practice  
- AI-powered writing band score feedback  
- Speaking practice with recording support  
- Countdown exam timer  
- Scholarship updates for international study  
- Dark mode premium interface  
- User login and progress tracking  
- Mobile-ready Android version (APK via Capacitor)
